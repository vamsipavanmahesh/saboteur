# Security policy

## Reporting a vulnerability

Email gvpmahesh@gmail.com. Do not open a public issue.

Include the affected version, a description, and steps to reproduce. We
acknowledge reports within 3 business days (IST) and aim to ship a fix or
mitigation within 30 days, coordinating disclosure with you.

## Scope

saboteur executes the code and tests of the project it runs on. Running it
against untrusted code is equivalent to running that code's test suite. Reports
about that are out of scope; reports about saboteur itself (for example writing
outside its working directory, or leaking environment data into reports) are in
scope.

## Supported versions

Only the latest released version receives fixes.
