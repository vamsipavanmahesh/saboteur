# Real-run feedback

Ran saboteur against a real project, with or without a pull request? Copy
the fields below into a new issue (the "Real-run feedback" template offers
the same fields) and tell us how it went. Short answers are fine.

## PR / repo

Which pull request or commit you ran, and the project you ran it on.

## Command I ran

The exact command line, including flags.

## Time it took

Wall-clock time, and the suite size if you know it.

## What worked

Anything that went well: a survivor that was real, a report that read well,
a fast run.

## What confused me

Output, wording or behavior you had to stop and think about.

## What was wrong

A false survivor, a crash, a slow run, a wrong count - anything incorrect.
Paste the relevant output.

## One thing I'd change

The single change that would have helped you most.
